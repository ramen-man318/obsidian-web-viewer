Obsidian Web Viewer — Development Plan

Version 2.0 of the Obsidian Web Viewer — a complete rewrite with side-panel navigation, in-browser editing, and proper Markdown parsing.

Motivation

The current viewer works but lacks polish:

  • No sidebar — navigation is all on the main page
  • Editing requires a separate editor
  • Indentation is broken (4 spaces → 2 spaces)
  • [[Wiki links]] aren't fully interactive

Architecture

Frontend

  • Sidebar + main content layout
    • Collapsible folder tree
    • Custom ordering with pin support
    • File search in sidebar
  • markdown-it-py for rendering
    • 2-space indent support
    • Wiki-link parsing → SPA-like navigation

Backend (Flask)

  • /api/list — directory tree JSON
  • /api/read — get file content
  • /api/save — write file content (new)
  • /api/search — grep search
